Text Box Test Page

Test Information

This page contains 8 text input fields that you can use to test the Selenium WebDriver script.

The text boxes are indexed from 0 to 7, and you can populate them individually using the script.

Expected Index Values:

  • Index 0: First Name (input type="text")
  • Index 1: Last Name (input type="text")
  • Index 2: Email (input type="email")
  • Index 3: Phone (input type="tel")
  • Index 4: Address (input type="text")
  • Index 5: City (input type="text")
  • Index 6: State (input type="text")
  • Index 7: Notes (textarea)

How to Use with Selenium:

  1. Save this HTML file locally
  2. Open it in your browser to verify it works
  3. Modify the Selenium script to navigate to this local file
  4. Run the script to test text box indexing and population

Local file path example: file:///path/to/your/test-page.html
